# 完备性审查

按[完备性标准](./完备性标准.md)核对当前稿本、Stage 4 底稿和上游适配器。

按主代理给的稿本、轮次和共享目录独立完成本项审查。只写本轮分配给自己的 Markdown 文件，交回其路径。结尾写明已查范围及结论（通过／有意见）；即使另一项已报问题也要查完。本轮稿件正文和状态由编写者、主代理分别维护。

按表格顺序记录意见。一条意见用一个标题，写稳定编号（首次用 C 前缀）、章节和左列原文（表外写段首，遗漏写补入位置）；正文引用证据，说明影响和最小改法。后续同一问题引用原编号，保留原话。澄清时按主代理指出的疑点在共享目录另交答复。

返修后复查时沿用上一轮已核实的结论。按编号检查改动及受影响的对应项，交代每项是否解决，并补记改动实际引入的问题。
