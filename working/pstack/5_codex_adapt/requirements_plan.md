# 编写或定向返修 cursor-codex.md

编写和返修均按以下两份标准验收。

- [写法标准](./写法标准.md)规定每行的去留、替换粒度和表外说明。
- [完备性标准](./完备性标准.md)规定怎样查全调用并核实 Codex 能否照做。

开始前确认 `../4_codex_openai_yaml/output/` 已包含上一阶段产出的 `agents/` 和 `skills/`。缺少产物就停在这里。

1. 首次编写或明确要求全文重跑时，将完备性标准中列出的上游适配器复制到本目录，命名为 `cursor-codex.md`。
2. 对照上游源码和 Stage 4 底稿，按完备性标准筛选映射项。把核实的漏项按原文的表格或短段落风格追加到文末。
3. 将标题改为 `# pstack in Codex`，保留 Cursor 列，把 Claude Code 列改为 Codex。按写法标准填写目标列，同步适配表外全局说明。

全文重跑会覆盖已有人工修改。需长期沿用的调整由用户写入对应标准或派工指令。

收到返修任务时，以当前稿和主代理本轮已裁定的返修清单为输入。只修改点名的行、表外段落或指定的补入位置。按意见编号在共享目录的本轮返修回执中写明实际改动和仍待处理的事项。初稿和返修均在稿件 frontmatter 写入 `status: wait-for-check`，交给主代理派发两项审查。
