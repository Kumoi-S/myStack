## Models

| Cursor | Codex |
| --- | --- |
| `~/.cursor/rules/pstack-models.mdc` | `$CODEX_HOME/pstack-models.md` |
| Role model slug ending in an effort or `<effort>-fast` | `<available-model> <supported-effort>` |
| `auto` or `inherit-parent` | Inherit the parent model and reasoning effort |
| Hard-coded `model:` in poteto-agent | Take the model from the calling role |
| Detect the models available to `Task` | List available models and reasoning efforts with `model/list` |

**setup-pstack** writes the dedicated model file as plain Markdown. Keep the defaults version, budget and role lines. Read it at the first role lookup in each session. `$CODEX_HOME` defaults to `~/.codex`.

For a Cursor default, use a confirmed model at the listed effort. For the ordinary coding default, use the session model. If it lacks the target effort, use its highest supported effort below the target. If no effort qualifies, ask for a supported pair. Apply the budget to the effort alone. Pass the selected model and reasoning effort separately. Leave both unset for an inheritance alias.

For **arena** and **interrogate**, keep one runner per panel entry, including aliases. Choose distinct available families for a model comparison. Report any missing family or vendor coverage. For Arena's cross-judge, use the first eligible model from another vendor. With no eligible judge, skip the judge and say so. For **show-me-your-work** and poteto-mode second opinions, report a missing cross-vendor review when no other vendor is available.
