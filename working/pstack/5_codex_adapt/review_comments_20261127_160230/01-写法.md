## 表外意见

**S-09 · Models · L46**　删去 “Keep the defaults version, budget and role lines.”。`skills/setup-pstack/SKILL.md:50–69` 已逐项规定文件内容。保留纯 Markdown、首次查角色时读取文件及默认根目录，这三处影响文件格式或寻址。

**S-10 · Models · L48**　与 S-05 一并修改。段落压为 “For the ordinary coding default, use the session model. Pass model and reasoning effort separately.”。`skills/poteto-mode/SKILL.md:92` 的固定默认型号要换掉；`skills/setup-pstack/SKILL.md:16,40–46` 已要求确认可用性、按预算调整 effort、取不超过目标的最高可用档并在无合适选择时询问。其余实值仍按 L41 的映射取用。

**S-11 · Models · L50**　保留的短注可写为 “For model comparisons, use distinct available Codex model families. Report any missing family or required cross-vendor review.”。`skills/setup-pstack/SKILL.md:42` 已按列表项（含别名）派人；`skills/arena/SKILL.md:19,30` 和 `skills/interrogate/SKILL.md:19` 已规定 panel、跨厂商选首个合格 judge 及跳过条件。第二意见的跨厂商要求见 `skills/show-me-your-work/SKILL.md:69` 和 `skills/poteto-mode/SKILL.md:100`。

**S-12 · Chats and worktrees · L82**　改为 “For **recall** and **automate-me**, include archived and desktop threads in the scoped search. For **show-me-your-work**, audit the current thread ID.”。`skills/recall/SKILL.md:20–21` 和 `skills/automate-me/SKILL.md:31–33` 已要求按工作区、时间和分片派人；`skills/show-me-your-work/SKILL.md:59` 的本次记录则确实要定位到当前线程。查询及翻页的调用留在 L75、L77。
