# 审查报告与复核

在分配的路径新建本轮 Markdown 报告，独立查完本项范围。按稿本顺序记录意见，每条以稳定编号、章节和左列原文定位。行号指向本轮稿本，表外用段首，漏项写明补入位置。每条意见直接用相对链接指向据以判定的单项要求，从报告所在目录计算路径。例如，共享目录内的报告可写 `[映射覆盖范围](../requirements/coverage.md)`。写明原始依据、影响和最小改法。结尾列已查范围及结论（通过／有意见），交回报告路径。主代理负责状态和裁定。

同一意见沿用编号，保留原话。收到追问时在共享目录另交答复。复查沿用先前已核实的结论，按编号检查点名改动及其直接影响，交代是否解决，并记录改动实际引入的问题。
