# GPT-6.1 Prompting Notes

## 1. 官方文档状态

截至 2026-11-19，OpenAI API 文档没有独立的 “Using GPT-6.1” 专属 Prompting Guide。官方 `Using GPT-6` 页面标题和正文明确覆盖 GPT-6 与 GPT-6.1，因此本文件将该页面中 GPT-6.1 的信息单独整理，避免虚构不存在的独立指南。

## 2. 已确认模型

- `gpt-6.1-sol`：复杂工作、较低成本；官方页面提及 Responses Multi-agent beta。
- `gpt-6.1-terra`：视觉推理和写作。
- Reasoning effort：GPT-6.1 Sol 不支持 `none`；GPT-6.1 Terra 支持 `none`。

## 3. Prompting 迁移建议

从 GPT-6 或更早版本迁移到 GPT-6.1 时：
1. 不要直接沿用旧模型的 reasoning effort；逐型号确认支持范围。
2. 对长任务定义完成条件、可逆假设和需要审批的边界。
3. 对多 Agent 工作流定义委派策略、子任务边界和结果验证方式。
4. 明确写作风格和输出格式，不要假设模型默认输出符合产品要求。
5. 对 `AGENTS.md`、skills 和其他上下文文件进行冲突审查。
6. 对工具调用和多轮 reasoning state 优先使用 Responses API，并按具体模型支持情况配置。

## 4. 不应推断的内容

- 不要把 GPT-6.2 Astra 的专属行为直接当成 GPT-6.1 的行为。
- 不要假设 GPT-6.1 Sol 与 Terra 的参数、成本、工具支持完全相同。
- 不要把模型页面中的定位描述当作正式 benchmark 保证。
- 不要因缺少独立 6.1 prompt guide 就自行编造所谓“6.1 专属 prompt token”或隐藏指令。
